### 3.2. Форматы медиафайлов

#### 3.2.1. Контейнеры и кодеки

Медиафайл состоит из двух частей:

- **Контейнер (контейнерный формат)** — «обёртка», хранящая структуру файла
- **Кодек** — алгоритм сжатия/раскодирования данных

**Примеры контейнеров:**

| Контейнер | Расширения | Содержимое |
| ----------- | ------------ | ------------ |
| MP4 | .mp4, .m4v | Видео (H.264), аудио (AAC) |
| Matroska | .mkv, .webm | Видео (VP9), аудио (Vorbis) |
| MP3 | .mp3 | Только аудио (MPEG-1/2 Audio Layer 3) |
| WAV | .wav | Только аудио (PCM, без сжатия) |
| JPEG | .jpg, .jpeg | Только изображение (JPEG) |
| PNG | .png | Только изображение (PNG) |

#### 3.2.2. Метаданные медиафайлов

**Метаданные** — служебная информация о файле, хранящаяся в заголовке или в специальных полях:

- Аудио: исполнитель, альбом, год, номер трека, обложка
- Видео: длительность, разрешение, битрейт, кодирование
- Изображения: EXIF (дата съёмки, параметры камеры), размер, глубина цвета

**Где хранятся метаданные:**

- MP3: ID3-теги (ID3v1, ID3v2)
- MP4/MKV: атомы/боксы в заголовке файла
- JPEG: EXIF-сегменты
- PNG: текстовые блоки tEXt, iTXt

```python
# Открываем файл
audio = MP3('track.mp3')

# Базовая информация
print(f"Длительность: {audio.info.length:.2f} сек")
print(f"Битрейт: {audio.info.bitrate} кбит/с")
print(f"Частота дискретизации: {audio.info.sample_rate} Гц")

# ID3-теги (если есть)
try:
    tags = ID3('track.mp3')
    if 'TIT2' in tags:
        print(f"Название: {tags['TIT2'][:1]}")
    if 'TPE1' in tags:
        print(f"Исполнитель: {tags['TPE1'][:1]}")
except Exception as e:
    print(f"Нет ID3-тегов: {e}")
```

```python
import cv2

cap = cv2.VideoCapture('video.mp4')

if cap.isOpened():
    # Чтение свойства видео
    width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
```

### 3.5. Конвертация форматов с помощью FFmpeg

**FFmpeg** — мощный инструмент для конвертации аудио/видео между форматами.

**Установка (Windows):**

1. Скачайте с [ffmpeg.org](https://ffmpeg.org/)
2. Распакуйте в системную папку
3. Добавьте путь к бинарникам в PATH

**Базовые команды:**

```bash
# Конвертация MP4 в MKV
ffmpeg -i input.mp4 output.mkv

# Извлечение аудио из видео
ffmpeg -i video.mp4 audio.mp3

# Конвертация изображения PNG в JPEG
ffmpeg -i photo.png photo.jpg
```

#### 3.5.1. Использование FFmpeg из Python

```python
import subprocess
import shutil

def convert_video(input_path, output_path):
    """Конвертация видео с помощью FFmpeg"""
    # Проверяем наличие FFmpeg
    if shutil.which('ffmpeg') is None:
        raise RuntimeError("FFmpeg не найден в системе")
    
    # Запускаем команду
    cmd = ['ffmpeg', '-i', input_path, '-y', output_path]
    result = subprocess.run(cmd, capture_output=True, text=True)
    
    if result.returncode != 0:
        raise RuntimeError(f"Ошибка FFmpeg: {result.stderr}")
    
    print(f"Конвертация завершена: {output_path}")

# Пример использования
try:
    convert_video('input.mp4', 'output.mkv')
except Exception as e:
    print(f"Ошибка: {e}")
```

## 6. Обработка ошибок

При работе с медиафайлами необходимо обрабатывать следующие ошибки:

1. **Файл не найден** — проверьте существование файла перед обработкой
2. **Неверный формат** — убедитесь, что расширение соответствует типу файла
3. **Отсутствует FFmpeg** — проверьте наличие программы в PATH
4. **Повреждённый медиафайл** — оберните операции чтения в try-except

Пример обработки ошибок:

```python
import os
from mutagen import File as MutagenFile

def safe_read_metadata(file_path):
    """Безопасное чтение метаданных с обработкой ошибок."""
    # Проверка существования файла
    if not os.path.exists(file_path):
        raise FileNotFoundError(f"Файл не найден: {file_path}")
    
    # Попытка чтения метаданных
    try:
        audio = MutagenFile(file_path)
        return audio
    except Exception as e:
        raise ValueError(f"Ошибка чтения метаданных: {e}")
```
