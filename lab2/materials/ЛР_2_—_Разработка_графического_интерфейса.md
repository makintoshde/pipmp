## 3. Теоретическая часть

### 3.1. Основы GUI-программирования

#### 3.1.1. Что такое GUI

GUI (Graphical User Interface) — графический пользовательский интерфейс, позволяющий взаимодействовать с программой через визуальные элементы: кнопки, окна, панели и т.д.

#### 3.1.2. Архитектура событийного цикла

GUI-приложения работают по **событийной модели**:

1. Приложение создаёт окно и виджеты
2. Запускается **event loop** (цикл обработки событий)
3. При взаимодействии пользователя генерируются события (клики, нажатия клавиш)
4. События обрабатываются соответствующими функциями

### 3.2. Сравнение PyQt6 и Tkinter

Обе библиотеки позволяют создавать GUI в Python, но имеют разные особенности:

| Характеристика | PyQt6 | Tkinter |
| --------------- | ------- | -------- |
| Встроенность | Внешняя зависимость | Встроен в Python |
| Возможности | Богатый набор виджетов | Базовый набор |
| Производительность | Высокая | Средняя |
| Кроссплатформенность | Да | Да |
| Документация | Отличная | Хорошая |

**Почему мы используем PyQt6:**

- Более современный и мощный фреймворк
- Лучшая поддержка сложных интерфейсов
- Интеграция с профессиональными инструментами Qt Designer

### 3.6. Сигналы и слоты

**Сигналы и слоты** — механизм связи между объектами в Qt.

#### 3.6.1. Как это работает

- **Сигнал (signal)** — событие, которое может быть отправлено
- **Слот (slot)** — функция, которая вызывается при срабатывании сигнала

```python
from PyQt6.QtWidgets import QPushButton

button = QPushButton("Нажать")

def on_button_clicked():
    print("Кнопка нажата!")

# Подключение сигнала clicked к слоту
button.clicked.connect(on_button_clicked)
```

#### 3.6.2. Пример: изменение текста при нажатии кнопки

```python
from PyQt6.QtWidgets import (QMainWindow, QPushButton, QVBoxLayout,
                            QWidget, QLabel, QApplication)
import sys

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        
        # Создаём виджеты
        self.label = QLabel("Привет!")
        self.button = QPushButton("Изменить текст")
        
        # Подключаем сигнал к слоту
        self.button.clicked.connect(self.change_text)
        
        # Создаём layout
        layout = QVBoxLayout()
        layout.addWidget(self.label)
        layout.addWidget(self.button)
        
        # Устанавливаем layout
        container = QWidget()
        container.setLayout(layout)
        self.setCentralWidget(container)
    
    def change_text(self):
        """Слот: изменяет текст label"""
        self.label.setText("Текст изменён!")

app = QApplication(sys.argv)
window = MainWindow()
window.show()
sys.exit(app.exec())
```

#### 3.7.2. Конвертация OpenCV изображения в QPixmap

OpenCV работает с NumPy-массивами (BGR), а Qt использует RGB. Нужно преобразовать формат:

```python
import cv2
from PyQt6.QtGui import QImage, QPixmap
from PyQt6.QtWidgets import QLabel

def opencv_to_qt_image(cv_image):
    """Преобразует изображение из OpenCV в QPixmap."""
    # OpenCV читает изображения в формате BGR
    rgb_image = cv2.cvtColor(cv_image, cv2.COLOR_BGR2RGB)
    
    h, w, channels = rgb_image.shape
    bytes_per_line = 3 * w
    
    # Создаём QImage
    qimage = QImage(rgb_image.data, w, h, bytes_per_line, QImage.Format.Format_RGB888)
    
    # Возвращаем QPixmap
    return QPixmap.fromImage(qimage)

# Пример использования
img = cv2.imread("photo.jpg")
if img is not None:
    pixmap = opencv_to_qt_image(img)
    label.setPixmap(pixmap)
```

### 3.10. Структура GUI-приложения

Типичная структура PyQt6 приложения:

```python
import sys
from PyQt6.QtWidgets import (
    QApplication, QMainWindow, QPushButton, 
    QVBoxLayout, QWidget, QLabel
)


class MainWindow(QMainWindow):
    """Главное окно приложения."""
    
    def __init__(self):
        super().__init__()
        self.init_ui()
    
    def init_ui(self):
        """Инициализация пользовательского интерфейса."""
        # Заголовок окна
        self.setWindowTitle("Моё приложение")
        self.setGeometry(100, 100, 800, 600)
        
        # Создаём центральный виджет
        central_widget = QWidget()
        self.setCentralWidget(central_widget)
        
        # Создаём layout
        layout = QVBoxLayout()
        
        # Добавляем виджеты
        self.label = QLabel("Привет, PyQt6!")
        self.button = QPushButton("Нажать")
        
        # Подключаем сигнал
        self.button.clicked.connect(self.on_button_click)
        
        # Добавляем в layout
        layout.addWidget(self.label)
        layout.addWidget(self.button)
        
        # Устанавливаем layout
        central_widget.setLayout(layout)
    
    def on_button_click(self):
        """Обработчик нажатия кнопки."""
        self.label.setText("Кнопка нажата!")


def main():
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())


if __name__ == '__main__':
    main()
```
